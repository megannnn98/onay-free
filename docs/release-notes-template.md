## onay-free @VERSION@ (один APK)

Неофициальная модификация ONAY! 3.6.5 (`kz.onay`): экран «Рядом» на вкладке Life и удалённая реклама. Код приложения тот же, что в @SOURCE_TAG@: подписанный набор split-APK объединён в один обычный `.apk`.

### Установка
1. Скачайте `onay-free-@VERSION@.apk`.
2. Откройте файл на телефоне и разрешите установку из этого источника, либо по USB: `adb install -r onay-free-@VERSION@.apk`.

Только ARM64, Android 7.0 и новее (проверялось на Android 14 и 16).

### Нужно ли удалять предыдущую версию
- **Оригинальное ONAY! из Google Play: да.** Подпись другая, поверх оно не встанет. Удаление стирает локальные данные приложения, потребуется войти заново.
- **onay-free 0.0.1: нет.** Подпись та же (сертификат сверен при сборке), ставится поверх с сохранением данных.
