## ONAY Free @VERSION@ — независимое приложение

Неофициальная модификация ONAY! 3.6.5; собрана из @SOURCE_TAG@. Этот APK имеет **отдельный Android-пакет `kz.onay.free`** и не подменяет официальное ONAY! (`kz.onay`).

### Установка
1. Скачайте `onay-free-@VERSION@.apk` (Android ARM64).
2. Установите как отдельное приложение. Официальное ONAY! удалять **не нужно**.
3. По USB: `adb install -r onay-free-@VERSION@.apk`.

### Обновления
- Обновления официального ONAY! через Google Play не обновляют и не удаляют независимый ONAY Free.
- Релиз `v0.0.1` имеет **другой пакет** (`kz.onay`): он не обновляется на этот APK, и данные автоматически не переносятся. Чтобы установить официальное ONAY! вместе с новой версией, сперва удалите старый `kz.onay`-мод, затем верните официальное ONAY!; новый ONAY Free устанавливается отдельно.
- Новый ключ подписи разрешён при выпуске: **@SIGNING_CHANGE@**. Для последующих обновлений `kz.onay.free` требуется сохранять тот же новый ключ и пароль.
