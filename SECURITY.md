# Безопасность

## Поддерживаемые версии
Исправления выходят только для последнего релиза (см. [Releases](../../releases)).

## Как сообщить об уязвимости
Не создавайте публичный issue. Напишите владельцу репозитория приватно (личное сообщение на GitHub) и опишите, что и как воспроизводится. Не прикладывайте реальные ключи, пароли и токены.

## Что считается важным
- утечка ключа подписи, пароля или токена (в репозитории, логах CI, артефактах);
- возможность подменить APK релиза или подпись;
- получение чужих данных (местоположение, аккаунт) через приложение.

## Правила проекта
- Ключ подписи и пароль хранятся вне репозитория (секреты GitHub Actions и локальная копия с правами 600). В Git их нет и не должно быть.
- Релизные APK подписываются одним и тем же ключом; смена ключа требует отдельного решения и явного предупреждения пользователям.
- Приложение не обходит серверную авторизацию ONAY!: маршруты и позиции транспорта доступны только вошедшему пользователю.
